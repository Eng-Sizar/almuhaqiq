# إضافة قضية جديدة

1. افتح `case-template.json` وانسخ كامل محتواه.
2. افتح `custom-cases.json` والصق القضية الجديدة داخل المصفوفة `[]`.
3. غيّر `id` إلى قيمة فريدة مثل `case_lost_necklace`، ثم غيّر `number` إلى رقم القضية التالي.
4. أضف الأدلة والمشتبه بهم وعقد الحوار والاختيارات.
5. شغّل `npm run lint` ثم `npm run build` قبل الرفع.

## قواعد مهمة

- لا تضع تعليقات داخل JSON.
- يجب أن يكون `startNodeId` موجوداً في `nodes`.
- كل `nextNodeId` داخل اختيار يجب أن يشير إلى عقدة موجودة.
- كل `clueId` في الرسائل أو الاستنتاجات يجب أن يكون موجوداً في `clues`.
- يجب أن تكون `id` للقضية فريدة وتحتوي حروفاً إنجليزية صغيرة وأرقاماً و`_` فقط.

التحقق التلقائي سيمنع البناء إذا كان مسار الحوار أو معرفات الأدلة غير صحيحة.
