# المحقق

لعبة تحقيق تفاعلية باللغة العربية مبنية باستخدام Next.js وTailwind CSS. لا تتطلب إنشاء حساب؛ يُحفظ تقدم اللاعب وإعداداته محلياً في المتصفح.

## التشغيل محلياً

```bash
npm install
npm run dev
```

افتح `http://localhost:3000`.

## النشر على Vercel

المشروع جاهز للنشر مباشرةً لأن Vercel يتعرف تلقائياً على تطبيقات Next.js.

1. ارفع المشروع إلى مستودع GitHub أو GitLab أو Bitbucket.
2. من لوحة Vercel اختر **New Project** ثم استورد المستودع.
3. اترك إعدادات Next.js الافتراضية كما هي، ثم اضغط **Deploy**.

يستخدم المشروع أمر البناء `npm run build`، ولا يحتاج متغيرات بيئة لتشغيل تجربة اللعب الأساسية.

> ملاحظة: شاشة لوحة الصدارة يمكنها الاتصال بـ Firestore عند توفر قواعد Firebase مناسبة. أما تجربة اللعب وحفظ التقدم المحلي فتعاملان دون تسجيل دخول أو إعدادات خارجية.

## إضافة قضية جديدة

أضف القضية إلى [custom-cases.json](src/data/cases/custom-cases.json) بالاعتماد على [case-template.json](src/data/cases/case-template.json). ستظهر القضية تلقائياً في التطبيق بعد البناء والنشر. توجد قواعد الكتابة الكاملة في [دليل القضايا](src/data/cases/README.md).

## توليد 3 قضايا يومياً بواسطة Gemini

توجد مهمة GitHub Actions في [.github/workflows/generate-daily-cases.yml](.github/workflows/generate-daily-cases.yml). تعمل يومياً عند **7:00 مساءً بتوقيت `Africa/Cairo`**، وتقوم بالآتي قبل النشر:

1. تنشئ ثلاث قضايا جديدة عبر Gemini.
2. تُجري مراجعتين مستقلتين لكل قضية: مراجعة منطق الأحداث ومراجعة مسارات اللعب والأدلة.
3. تصلح القضية تلقائياً إن وُجدت ملاحظات، حتى ثلاث محاولات كحد أقصى.
4. تتحقق برمجياً من المعرفات، الأدلة، الاستنتاجات، كل عقد الحوار، المسارات، والنهايات.
5. لا تحفظ أي قضية إذا فشل أي جزء من المراجعة، ثم تبني المشروع قبل تنفيذ commit واحد للقضايا المعتمدة.

للتشغيل، ارفع المشروع إلى GitHub ثم أضف السر `GEMINI_API_KEY` من **Settings → Secrets and variables → Actions**. لا تضع المفتاح في ملفات المشروع. عند ربط المستودع بـ Vercel، يؤدي الـ commit اليومي إلى نشر القضايا الجديدة تلقائياً.
